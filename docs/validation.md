selection, distinct templates, preserving personal edits on repeat setup,

following SETUP.md so user-specific edits survive. All twelve skill validators pass. Voice examples were reviewed against the requested lowercase, sparse

## Covenant and removal of obsolete plumbing

The directive is now a persona-independent, ten-article Covenant. Setup tests
verify identical mission text for both personas, preserved user edits, and an
explicit recovery error when an established persona's directive is missing.
That recovery check prevents silently substituting a default for lost user text.

Removed the redundant workflow directory, the excluded local-script provider,
its resolver exceptions, and an unreferenced trust-scoring helper and types.
CLI guidance and documentation point directly to the operational skills.
