# Job Search bootstrap

Locate this kit's repository root (the directory containing `SETUP.md` and
`package.json`). Read `AGENTS.md`, then `SETUP.md`; that is the canonical
interview and construction procedure. Offer the generic/goblin choice there,
then read the generated directive, identity and voice and use them throughout
the interview. Do not create a separate questionnaire
or infer candidate preferences from bundled connector examples.

Read existing private onboarding progress before asking questions. Extract
facts from material the user already supplied, distinguish confirmed facts
from assumptions, and ask only consequential gaps in small related batches.
Build useful campaign files progressively. Start requested operational work with the facts needed for that action;
continue the interview alongside it. Deferred questions stay in private
onboarding state and do not block independent work. Preserve any user-supplied
directive verbatim under the instruction order in AGENTS.md. Installing this skill does not authorize external
messages or applications.
