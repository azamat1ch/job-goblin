# Build a voice from evidence

Invite one or two messages the user would actually send, or write contrasting
short drafts for the same realistic recipient. Ask which sounds like them and
what feels false. A polished CV is weak evidence of everyday message style.

Save a small section in preferences.md with:

- samples or links to local supplied samples
- preferred register for recruiters, peers, founders and formal forms
- language, spelling convention, typical length and punctuation
- words they use, words they dislike, and the reason when helpful
- one corrected sample each for a cold message and a reply

Example exercise with synthetic facts: candidate improved reconciliation time
from two days to four hours; a finance operations team is hiring. Draft a short
message to a recruiter, then a scheduling reply. Ask for wording corrections,
not a personality label. Keep sample facts separate from real candidate evidence.

A later correction updates this section. It does not become a new global rule
for every candidate or change the conversational assistant persona.
